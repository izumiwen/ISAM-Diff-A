# 治理文件導覽

本目錄存放正式研究工作必須遵循的規範；各文件彼此互相引用，請由需求對應的入口開始閱讀。

| 文件 | 適用時機 |
|---|---|
| [`experiment_protocol.md`](experiment_protocol.md) | 撰寫或執行正式實驗前 |
| [`subagent_workflow.md`](subagent_workflow.md) | 委派正式實驗規劃或執行獨立驗收前 |
| [`run_standard.md`](run_standard.md) | 執行訓練、評估、推論或資料集驗證前 |
| [`isam_diff/`](isam_diff/) | 檢閱 ISAM-Diff 候選研究計畫與路徑映射 |

所有工作仍以專案根目錄的 [`AGENTS.md`](../AGENTS.md) 為優先規則；正式實驗開始前，亦須先讀取 [`reports/experiment_log.md`](../reports/experiment_log.md) 的相關最新條目。
