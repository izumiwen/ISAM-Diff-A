# 最終主張稽核模板

僅在每個相關正式實驗均有獨立稽核後使用。此文件不取代個別稽核報告。

```md
# <study_id>: 最終主張稽核

## Supported Claims

### Claim S1
- 主張：
- 支持實驗與稽核：
- 原始產物路徑：
- 效果量與不確定性：
- 限制：

## Conditional Claims

### Claim C1
- 主張：
- 成立條件：
- 支持實驗與稽核：
- 失敗邊界：

## Unsupported Claims

### Claim U1
- 原訂主張：
- 未獲支持的理由：
- 缺少的證據：
- 建議後續實驗：

## 禁止措辭檢查

- [ ] 沒有未經證據的 zero-shot 主張。
- [ ] 沒有缺乏端到端延遲量測的速度主張。
- [ ] 沒有只依單一資料集的泛化主張。
- [ ] 沒有只以 PSNR 支持的結構保留主張。
- [ ] 沒有缺乏 matched Transformer control 的 Mamba 優勢主張。
```
