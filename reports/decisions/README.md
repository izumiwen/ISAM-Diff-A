# 研究決策紀錄

每個改變研究問題、方法或 baseline 身分、資料集 split、主要指標/評估程序、接受門檻/停止規則，或其他研究主張邊界的決策，應建立為獨立檔案：`{decision_id}.md`。

請從 [`../templates/decision_ledger_template.md`](../templates/decision_ledger_template.md) 建立新檔；不要覆寫既有決策。若決策改變研究狀態，依 `../../docs/experiment_protocol.md` 的 material trigger 同時追加 [`../experiment_log.md`](../experiment_log.md)。
