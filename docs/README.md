# 治理文件導覽

本目錄存放本專案的 canonical 治理規範。先讀根目錄的 [`AGENTS.md`](../AGENTS.md)，再依工作責任範圍閱讀下列文件；不要把各文件的規則全部累加，而應優先採用該主題的負責文件。

| 文件 | 適用時機 |
|---|---|
| [`experiment_protocol.md`](experiment_protocol.md) | Formal/非正式範圍、material deviation、研究證據、接受、帳本與封存觸發 |
| [`subagent_workflow.md`](subagent_workflow.md) | 角色分工、獨立性、委派順序與稽核狀態 |
| [`run_standard.md`](run_standard.md) | run 身分、執行證據、retry、資料執行安全與環境/工具鏈操作 |
| [`governance.md`](governance.md) | Non-normative 導覽摘要；只協助選擇上述 canonical 文件 |

Formal Experiment 規劃或執行前必須讀取 [`reports/experiment_log.md`](../reports/experiment_log.md) 的最新相關條目。決策會改變工程工作、證據重用或研究主張/計畫修訂前也必須閱讀；例行局部修復不必重讀無關帳本歷史。

`governance/` 保存舊版治理文件，不屬於目前 canonical governance set，也不作為現行工作入口。
